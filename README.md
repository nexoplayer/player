# MRK Player

Downloads for the MRK Player app on Android TV, Google TV, Amazon Fire TV and Android phones & tablets.

**Get the latest version:** [Releases](https://github.com/mrkplayer/player/releases/latest)

## Install on Fire TV / Android TV

1. Install the **Downloader** app from the Amazon Appstore or Google Play.
2. Fire TV: allow Downloader to install apps (*Settings → My Fire TV → Developer options*).
3. In Downloader, enter **player-platform-six.vercel.app/get** and install.
4. Open MRK Player and follow the on-screen steps to activate your TV.

Need help? Visit the website and chat with us.
